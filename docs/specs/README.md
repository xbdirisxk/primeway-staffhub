# Specs

- `staffhub-spec-v3-ai.md` — **build spec for Claude Code (source of truth)**.
- `staffhub-spec-v3.md` — human-readable version (same content as the Word file).
- `design/prototype/` — **clickable design prototype** (97 screens, aligned with spec v3). Open `index.html` in a browser. Its `README.md` lists which screens are Phase 1, 2 or 3, and what changed to match v3. If a screen and the spec disagree, the spec wins.
- `design/` — design system notes from the original prototype: `design-spec.md`, `design-system.css`, `icons.js`, `prototype-notes.md`. These still show the old teal accent and five roles; the prototype above is the current visual reference.

A new spec version replaces these files in a pull request, with the changes summarised in its "Changes from" section.
